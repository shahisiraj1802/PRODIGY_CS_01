# Caesar Cipher - PRODIGY_CS_01

## Description
This project implements the Caesar Cipher algorithm using Python. The program allows users to encrypt and decrypt messages using a shift value.

## Features
- Encrypt messages
- Decrypt messages
- Supports uppercase and lowercase letters
- Preserves spaces and symbols

## Technologies Used
- Python

## How to Run

```bash
python caesar_cipher.py
```

## Example

Input:
welcome

Shift:
2

Output:
ygneqog
